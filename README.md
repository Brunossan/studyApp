studyApp - Features

This project provides the following high-level features:

- Store and organize study content (title, category, original text, notes).
- Link memorization techniques to specific content items.
- Support multiple technique types: acronyms, mind palace, associative stories, spaced repetition, mind maps, and others.
- Create techniques manually or with AI assistance.
- Mark techniques as favorites for quick access.
- Record creation and update timestamps for content and techniques.
